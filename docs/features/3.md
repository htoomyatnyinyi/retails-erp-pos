Local Database ကို ဖျက်လိုက်သည့်အခါ (Clear Database ပြုလုပ်ချိန်) Cloud မှ Data များကို မဆွဲလာနိုင်ဘဲ **"ဘာမှ မပေါ်လာသည့် ပြဿနာ"** ၏ အဓိက အကြောင်းအရင်းကို စစ်ဆေးတွေ့ရှိပြီး ပြင်ဆင်ပြီးစီးပါပြီ။

### 🔍 ပြဿနာဖြစ်ရသည့် အကြောင်းအရင်း (Root Cause)

1. **Stale Sync Cursor in AsyncStorage:**
   - စနစ်တွင် Sync မြန်ဆန်စေရန်အတွက် နောက်ဆုံး Sync လုပ်ခဲ့သည့် အချိန်မှတ်တမ်း (Timestamp) ကို `AsyncStorage` တွင် `offline-sync-cursor` Key များအဖြစ် သိမ်းဆည်းထားပါသည်။
2. **Clear Database ချိန်တွင် Cursor ကျန်နေခြင်း:**
   - ယခင်က `clearOfflineDatabase()` ပြုလုပ်သည့်အခါ SQLite Database ထဲရှိ Data များကိုသာ ဖြတ်ပစ်ခဲ့ပြီး `AsyncStorage` ထဲရှိ `offline-sync-cursor` များ (ဥပမာ `1726589999999`) ကို **မဖျက်ဘဲ ကျန်ရစ်ခဲ့ပါသည်**။
3. **Incremental Sync ၏ မှားယွင်းသော ဆုံးဖြတ်ချက်:**
   - Database ကို Clear လုပ်ပြီးနောက် Sync ပြန်လည် စတင်သည့်အခာ စနစ်က `AsyncStorage` ထဲရှိ ယခင် Timestamp `1726589999999` ကို ဖတ်မိပါသည်။
   - ၎င်းနောက် Cloud Server သို့ `getSyncProducts({ since: 1726589999999 })` ဟု မေးလိုက်သည့်အခါ Server တွင် ၎င်းနောက်ပိုင်း ပြောင်းလဲသွားသော ကုန်ပစ္စည်း မရှိသဖြင့် `[]` (Empty) သာ ပြန်ပေးပါသည်။
   - စနစ်က "Data သစ်မရှိပါ" ဟု ယူဆကာ Cloud မူလ Data များအားလုံးကို ပြန်မဆွဲတော့ဘဲ **Full Pull (အစအဆုံး ဆွဲယူခြင်း) ကို ကျော်သွားခဲ့သဖြင့်** Local DB မှာ 0 ရောဂ် ဖြစ်ကျန်ခဲ့ပြီး UI တွင် ဘာမှ မပေါ်လာခြင်း ဖြစ်ပါသည်။
